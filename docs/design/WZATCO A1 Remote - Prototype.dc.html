Held for the dark

  • Every target is at least 58 px tall with 6 px gutters, so keys are distinguishable by thumb position alone.
  • Fixed geometry: rows never reflow, so muscle memory survives updates.
  • The keypad never scrolls — all twelve functions sit on one face.
  • Press feedback is a full-cell accent flash plus a 12 ms haptic tick, readable in peripheral vision.
